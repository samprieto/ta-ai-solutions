What it does

The problem: Distributed task management across tools like Google Keep, Notion, and Excel creates invisible urgency gaps. Work gets lost, prioritization is inconsistent, and reporting to managers requires manual effort that competes with execution time.

The solution: Quest Keeper consolidates daily task management into a single gamified interface. An AI engine extracts action items from any input (pasted text, uploaded screenshots, email threads, or meeting transcripts) and automatically allocates them across an 8-hour work budget. Progress is visible in real time, and a one-click daily update delivers a structured status report to the direct manager.

  • ✓
    AI task extraction from text and screenshots via Gemini Vision: no manual entry required
  • ✓
    Smart calendar with public holidays pre-seeded, custom-capacity days, and business-day-aware scheduling
  • ✓
    Editable task drawer with subtasks, descriptions, deadlines, and a built-in countdown timer with pause/resume
  • ✓
    Gamification layer: streaks, daily completion targets, end-of-day accountability, and unlockable features tied to performance
  • ✓
    One-click daily manager update: generates and delivers a structured status report automatically

How it helps the team

Before

Task management was fragmented across multiple tools with no unified view of urgency or daily capacity. An estimated 2 to 4 hours per day were lost to replanning and context-switching, with additional time spent composing manual status updates for the manager.

After

Data collection in progress. This section will be updated once the solution is fully deployed.

  • Saves approximately 2 to 4 hours per week per user by eliminating replanning, context-switching, and manual reporting (estimated)
  • Improves prioritization consistency through a structured 4-tier hierarchy with visible daily capacity
  • Reduces reporting overhead through automated one-click daily status updates to the direct manager
  • Designed to scale: the codebase can be cloned per user, with a multi-tenant version on the roadmap for broader People Team rollout
